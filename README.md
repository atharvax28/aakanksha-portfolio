# Aakanksha Tayade — Portfolio

A personal portfolio site built with Next.js and a Radix UI + Tailwind (shadcn/ui) component system.

🔗 **Live:** https://aakankshatayadeportfolio.vercel.app

## Tech stack

`Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `Radix UI / shadcn/ui`

## Getting started

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build    # production build
```
